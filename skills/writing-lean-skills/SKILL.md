# Writing Lean Skills

## Overview

Produces lean skill documents: every line changes agent behavior, nothing repeats, and structure carries meaning instead of prose. Works on any `SKILL.md` and its reference docs.

## Agent workflow

Follow this skill when the user asks to review a skill for verbosity, write a new skill lean from the start, or rewrite an existing skill into a lean version. Match one **Recipes** row; open exactly that reference. All recipes share the finding categories and lean strategies in [lean-contract.md](references/lean-contract.md).

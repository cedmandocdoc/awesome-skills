# Marketing Types

## Overview

The marketing types a campaign can use, as one table that Target, Roll-out, Assets, and Execution read. Adding a type means adding a row.

## Guidelines

### Types

Every type ends in drafts the user approves and sends by hand.

| Type (`utm_medium`) | Audience source | Assets | Channel | Speed | Use when |
| --- | --- | --- | --- | --- | --- |
| `outbound` | Named prospects researched into `prospects.csv` | Personal email or DM; free audit or demo offer | Email from `mail.<domain>`; DMs | Days | No users yet; B2B or local businesses |
| `referral` | Existing happy users | Personal ask with the referrer's own link | Email or DM from the founder | Days–weeks | Some users like the product |
| `content` | Followers and the platform's algorithm on the project's own accounts | Video post, text post | TikTok, Instagram, LinkedIn, Facebook, X, YouTube | Weeks–months | The message is proven; the long game |
| `community` | Groups where the segment already asks for help (subreddits, Facebook groups, Discord, Slack) | A helpful answer or post that solves the problem first | The group | Days | The segment gathers in one place |
| `partnerships` | Businesses that serve the same segment (newsletters, agencies, tools) | Partner pitch | Email (counts toward caps) | Weeks | An adjacent audience exists |
| `paid` | Platform targeting | Video; targeting spec the user enters in the ads manager | Meta, TikTok, LinkedIn ads | Days | Direct outreach has proven the message |

### Choosing

- While the product has no users, start direct (`outbound`, `community`, `referral`) before broadcast (`content`, `paid`).
- One campaign: one segment, one problem, one or two types.
- `paid` only after a direct campaign concluded with its goal met.

### Writing rules per asset

| Asset | Rules |
| --- | --- |
| Cold email | Plain text, ≤ 120 words. First line is a specific fact about them (`why` in `prospects.csv`); then their pain, one proof, one low-effort ask (a reply). Link only when it helps. Opt-out line last |
| Follow-up | ≤ 60 words, new value (a result, a short demo link), same thread as `Re: <first subject>` |
| DM | ≤ 60 words; same order as cold email without the opt-out line |
| Community post | Answers the question in full; the product appears once, as a disclosed option |
| Post caption | First line is the hook; one message; CTA with the link |
| Partner pitch | What their audience gets, the proof, the ask, the effort on their side |
